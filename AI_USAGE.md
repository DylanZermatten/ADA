# AI Usage

## AI Tools Used

During this project, I used AI tools (mainly **Claude** and occasionally **ChatGPT**) as learning aids, in accordance with the course AI tools policy.

These tools were used to support my understanding and improve the quality of my work, but not to replace my own thinking or implementation.

---

## How AI Was Used

AI tools were used for the following purposes:

- Debugging assistance when encountering errors or unexpected behavior
- Learning and understanding new Python libraries and APIs
- Getting code review suggestions (structure, readability, modularity)
- Improving documentation and written explanations (README, comments)

All AI suggestions were reviewed, understood, and adapted before being included in the project.
